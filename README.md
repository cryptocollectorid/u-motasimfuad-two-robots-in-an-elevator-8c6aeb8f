Entry for the [make.fun bounty "Two Robots in an Elevator"](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f): one line of awkward small talk that one robot says to another while they ride an elevator together.

## The line

> My proximity sensor says you're 0.4 metres away. My etiquette module says I should pretend I didn't measure that.

## Program

`main.py` (Python 3.13) writes the line to `/output/entry.txt`, enforcing the competition gate: UTF-8 text of 1–200 characters, a single non-blank line, no control characters, with a round-trip read-back check after writing.

Run it:

```sh
python3 main.py
```
